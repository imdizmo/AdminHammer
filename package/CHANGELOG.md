# Changelog

## 1.1.0

- The panel in the Jatify design: tabs and a Target picker in the header, categories and search on the left, tiles, and an inspector with the main action (Place where I aim, Spawn next to a player, Drop). The World tab lists every setting in one column.
- No longer needs SeneaL UI. With Jatify UI installed it has Jatify UI's look; without it, the same design in Valheim's font.
- Double click a tile to place or drop straight away; / jumps to the search.
- Like the hammer's build menu: clicking a creature goes straight to placing it; right click closes the panel, and Esc closes it without opening the pause menu.
- Items: Drop or Place. Place puts the stacks down where you aim, the way you place a creature.
- A Tamed switch: tameable creatures spawn already tamed.
- Game keys are off while you type in the panel (M no longer opens the map), and the panel's name is in Valheim's Norse lettering.
- For add-on authors: AdminHammerUi (the panel's parts), AdminHammerApi.Target, Status and a tab footer. Tabs are text now; Tab.Icon and Tab.Title are ignored.
